# Francisco Arce — Resume Website

A responsive, recruiter-first one-page professional portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and resume content
- `styles.css` — responsive design and animations
- `script.js` — mobile navigation, scroll reveals and rotating hero message

## Run locally
Open `index.html` in a browser, or run a simple local server from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Recommended deployment
- GitHub Pages
- Netlify
- Vercel

This version removes broad AI-style wording and rewrites the page around evidence: scope, action, result and context.
